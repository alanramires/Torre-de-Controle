# Ideias

## Retratos de personagens por link externo

- Oferecer os retratos padrão dos arquétipos incluídos no sistema.
- Para uma imagem personalizada, permitir informar o link de uma imagem hospedada externamente pelo jogador, em vez de enviar o arquivo para a Torre.
- Aceitar apenas imagens JPG/JPEG e PNG; validar o formato real do conteúdo, não apenas a extensão do link.
- Guardar na ficha somente a URL. Não hospedar nem persistir o arquivo personalizado nos arquivos ou dados do jogo.
- Objetivo: reduzir abusos e evitar armazenar imagens impróprias no jogo. A escolha do conteúdo e sua hospedagem externa ficam por conta de quem fornece o link; links externos ainda podem apontar para conteúdo impróprio.
- Como a Torre é uma ferramenta exclusiva do mestre, o mestre informa o link recebido do jogador, sem exigir conta ou tela de jogador.
- Se o link estiver indisponível ou não corresponder a um formato aceito, mostrar o retrato padrão do arquétipo.

Registrado em 2026-10-13. Proposta para implementação futura.
